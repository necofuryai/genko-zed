# Security Policy

## Supported versions

Security fixes target the latest published Genko version.
Older versions may not receive fixes.

## Reporting a vulnerability

Use [GitHub Private Vulnerability Reporting](https://github.com/necofuryai/genko-zed/security/advisories/new) to report a suspected vulnerability.
Do not disclose vulnerability details in a public issue or pull request.

Include the following information when available:

- The affected Genko version and installation method
- The operating system and architecture
- The expected and observed security impact
- Minimal reproduction steps using fictional data
- Relevant logs with credentials, personal information, and unpublished writing removed
- A possible mitigation or fix, if known

The project does not currently guarantee a response or remediation time.
Please allow the maintainer to investigate and coordinate disclosure before publishing details.
